**What is Generative AI ?** 

Generative AI is type of Artificial Intelligence that create new content such as text, image, videos, music and code based on user prompts.

![Generative AI Image.png\|493](/img/user/Image/Generative%20AI%20Image.png)

**What are the Generative AI Tools? Explain all tools in one line**
Generative AI tools are software applications that use artificial intelligence to create new content such as text, images, videos, audio, code, and presentations based on user prompts.

**Categories of Generative AI Tools**
**Text Generation**: ChatGPT, Claude, Gemini
**Image Generation**: Fotor, Watermark Remover, Imagine Art, Lexica, Remini, Cleanup Pictures, Remove Bg, Meshy-3d image
**Video Generation**: Runway, Synthesia, Viggle, HeyGen, PixVerse AI, VEED, Animaker, Skybox AI(3D)
**Audio & Music Generation**: ElevenLabs, Suno AI, Moises Studio, MiniMax 

| Tool               | Primary Use                                                                  |
| ------------------ | ---------------------------------------------------------------------------- |
| **ChatGPT**        | Generates text, answers questions, writes code, and assists with learning.   |
| **Google Gemini**  | AI assistant for text, coding, images, and reasoning.                        |
| **Claude**         | Creates and summarizes text, analyzes long documents, and answers questions. |
| **Perplexity AI**  | AI-powered search engine with cited answers.                                 |
| **GitHub Copilot** | Helps developers write and debug code.                                       |
| **Writesonic**     | Produces SEO articles and marketing copy.                                    |
| **Grammarly AI**   | Improves grammar, tone, and writing style.                                   |
| **Adobe Firefly**  | Creates and edits images and graphic designs with AI.                        |
| **Runway ML**      | Generates and edits AI videos.                                               |
| **Pika**           | Creates videos from text or images.                                          |
| **Synthesia**      | Produces AI avatar videos from text.                                         |
| **ElevenLabs**     | Generates realistic AI voices and speech.                                    |
| **Suno AI**        | Creates songs and music from text prompts.                                   |
